# 5 分钟面试演示指南

演示前启动后端和前端，使用本地演示数据。不要在演示过程中执行 reset_demo_data.sql；如需重建数据，应在演示前备份后单独完成。

## 0:00–0:35｜进入广场

使用账号 neighbor_a 登录，展示社区首页、搜索、分类、交易方式和状态筛选。指出本地图片、价格/交易方式、新鲜度、状态和地点信息。

## 0:35–1:25｜发布与 AI 估价

进入发布页，填写一个固定价格物品。点击“AI 帮我估价”，展示建议区间、推荐价、置信度、因素和不确定性；说明信息不足、429、超时都会保留手工定价降级。不要把估价描述成实时成交价。

## 1:25–2:00｜切换账号表达想要

退出并切换到 neighbor_b，打开刚才的物品详情，选择未来交接时段并点击“我想要”。可演示取消后再次申请，说明同一用户和物品不会产生重复意向。

## 2:00–2:50｜发布者确认与交接卡

切回 neighbor_a，在详情页打开意向名单，确认 neighbor_b。展示公共地点、交接时段和“待交接”交接卡；说明交接双方均可取消，取消后物品恢复可领取。

## 2:50–3:25｜留言与一层回复

在未完成物品详情页用 neighbor_b 留言，例如询问配件或使用痕迹；切回 neighbor_a，以发布者身份回复。指出回复只允许一层，物品完成后留言和回复只读。

## 3:25–3:55｜完成归档

使用发布者账号在交接卡点击“标记已送出”。展示物品和交接进入完成状态，并保留历史记录。

## 3:55–4:40｜社区数据看板

打开“社区数据”，展示本月发布、本月成交、当前在售三项指标，以及最快完成和最想要但尚未成交排行。说明这些数字来自数据库 SQL 聚合，不是前端假数据。

## 4:40–5:00｜工程收束

补充说明 Session 认证、Flyway V1～V5、后端代理 LLM、45 秒超时、60 秒频率限制、AI 失败手工降级和移动端响应式适配。最后说明当前为本地面试演示配置，尚未配置正式公网生产部署。
